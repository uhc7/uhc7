## 👋 About Me

I'm a **DevOps / DataOps Engineer** focused on building reliable automation, cloud infrastructure, and data engineering workflows.

I enjoy working at the intersection of **software engineering, cloud platforms, data pipelines, and automation** — especially taking manual operational processes and turning them into repeatable, testable workflows.

### 🚀 What I'm working on

* 🔭 Building **DataOps and data ingestion workflows**
* ⚙️ Developing **CI/CD automation with GitHub Actions**
* ☁️ Working with **Azure cloud services and containerized workloads**
* 🐍 Building **Python-based validation and automation tooling**
* 🗄️ Exploring **DuckDB, DuckLake, PostgreSQL, and modern data architectures**
* 🔐 Improving **DevSecOps and automated security scanning workflows**
